MULTIPOINT AUTOCLICKER — СБОРКА EXE ЧЕРЕЗ GITHUB

Что понадобится:
- Аккаунт GitHub (бесплатного аккаунта достаточно).
- Браузер.
- Архив с файлами проекта.

ШАГ 1. Создай репозиторий
1. Открой https://github.com/new
2. Repository name: MultiPointAutoClicker
3. Выбери Public или Private — как тебе удобнее.
4. Нажми Create repository.

ШАГ 2. Загрузи файлы проекта
1. Открой созданный репозиторий.
2. Нажми Add file → Upload files.
3. Распакуй этот архив на компьютере/телефоне.
4. Загрузи ВСЕ файлы и папку .github (включая .github/workflows/build.yml).
   Важно: GitHub должен увидеть файл по пути:
   .github/workflows/build.yml
5. Нажми Commit changes.

ШАГ 3. Запусти сборку
1. Открой вкладку Actions в репозитории.
2. Если GitHub спросит разрешение на workflows, нажми I understand my workflows, go ahead and enable them.
3. В списке слева выбери Build Windows EXE.
4. Если автоматическая сборка после загрузки уже завершилась — можешь сразу перейти к шагу 4.
   Иначе нажми Run workflow → Run workflow.

ШАГ 4. Скачай EXE
1. Открой завершённый запуск со значком зелёной галочки.
2. Прокрути вниз до раздела Artifacts.
3. Скачай MultiPointAutoClicker-Windows-x64.
4. Распакуй ZIP — внутри будет MultiPointAutoClicker.exe.

Результат:
- Это настоящий автономный Windows x64 EXE.
- Python не требуется.
- .NET Runtime на компьютере тоже не требуется.
- Файл будет доступен в Artifacts 30 дней.

Если сборка красная:
Открой запуск Actions и пришли скриншот или текст ошибки — помогу исправить.

Безопасность:
GitHub Actions собирает проект из загруженных тобой исходников. Не загружай в репозиторий личные пароли или секреты.
