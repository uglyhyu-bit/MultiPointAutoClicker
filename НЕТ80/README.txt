MULTIPOINT AUTOCLICKER — Windows 10/11 x64

Это нативное приложение C# Windows Forms. Python не используется.
В комплекте исходный проект и скрипт сборки автономного EXE.

КАК ПОЛУЧИТЬ EXE:
1. Установи .NET 8 SDK для Windows x64:
   https://dotnet.microsoft.com/download/dotnet/8.0
   Выбери .NET SDK 8.x для Windows x64 (не Runtime).
2. Распакуй архив в обычную папку.
3. Дважды запусти BUILD_EXE.bat.
4. После успешной сборки откроется папка с MultiPointAutoClicker.exe.
   EXE публикуется self-contained — установленный .NET для запуска уже не нужен.

УПРАВЛЕНИЕ:
F6 — добавить точку в текущем положении курсора.
F8 — запуск.
F9 — остановка.
Координаты фиксируются при добавлении точки.
В таблице можно редактировать интервалы и длительность удержания.
Кнопка «Обновить координаты» берёт новые координаты курсора для выбранной точки.

ЛОГИКА:
- Интервал отсчитывается после завершения удержания ЛКМ.
- Точки выполняются последовательно, поскольку физическая левая кнопка мыши общая.
- Пока одна точка удерживает ЛКМ, другие ждут.
- Для изменения списка останови автокликер.
- Дробные секунды поддерживаются (например, 0.5).

ПРИМЕЧАНИЕ:
Это комплект для сборки EXE, а не уже скомпилированный Windows EXE.
Сборка выполняется на Windows с установленным .NET 8 SDK.
Используй автоматизацию только там, где она разрешена правилами приложения/игры.
